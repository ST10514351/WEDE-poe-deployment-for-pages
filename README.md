**New Beginnings Foundation**

For part 1 of the WEDE POE we were tasked with choosing a company in which we would code a website for, one of the options
was an NPO. I chose to create a fictional company that specialises in improving the lives of the 
homeless by guaranteeing them a second chance at life through rehab programs and job offers.

**Student information**
- Name: Kamohelo Morebodi
- Student number: ST10514351
- Qualification: Higher Certificate in Mobile App and Web Development

**Website Goals and Objectives**
- To raise awareness of the issue and hold people accountable
- The website aims to create a channel in which people can donate to a cause greater than themselves

**Key features and Functionality**
- Website has a donate page which allows you to click common amounts or enter a custom amount
- Website has a feedback page in which you can offer positive or constructive to any of the stakeholders; web developers, management, etc
- Website has a contact page where you can specify which stakeholder you are contacting and for what reason; as in volunteering or larger, more private donations

For Part 1 of the POE we had to push th2 basic HTML code with no CSS or JavaScript. 
The goal was also to define our project specs and thoroughly determine who we are coding this for and what they would realistically expect

1. (2026/09/13 - 2026/10/05)

- The main HTML content of the pages has been revised. Part of the feedback was that there was nowhere near enough content to populate the page, leading to poor use of semantic HTML tags. This update has addressed both of the above.

- - Many of the CSS tags found throughout the document allow for multiple items across all pages to be designed simultaneously
